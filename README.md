# Student Task Manager

A simple Python console app to manage student tasks.

Project status: Complete

## Features
- Add tasks (empty titles are rejected)
- Display all tasks
- Mark tasks as completed
- Delete tasks by id

## Setup
1. Install Python 3.8 or newer.
2. Clone the repository:
   git clone https://github.com/abeehashoukat/student-task-manager.git
3. Go into the folder:
   cd student-task-manager

## Usage
Run the app with:

    python main.py

Choose an option from the menu: 1 Add, 2 Show, 3 Mark complete, 4 Delete, 5 Exit.

## Running Tests
    python -m unittest discover -s tests -v
